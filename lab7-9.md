Лабораторна робота 7-9
Цей веб-додаток реалізує інтерактивну інкрементальну гру-клікер «Cyber Clicker Pro» на базі React та Vite.

Що робить програма
Нараховує ігрову валюту (кредити) за активні кліки по кнопці та щосекундно в пасивному режимі.

Дозволяє купувати та прокачувати 5 різних апгрейдів у магазині для збільшення пасивного доходу.

Реалізує систему «Престижу» — скидання прогресу в обмін на монети, які назавжди дають +10% до доходу.

Дозволяє миттєво змінювати візуальне оформлення сторінки (Світла, Темна або Неонова теми).

Додає елемент випадковості: покупку кейсів із шансом 50/50 та випадкові хакерські атаки, що тимчасово зменшують показники.

Автоматично зберігає прогрес у пам'ять браузера та нараховує дохід за час, проведений офлайн.

Основні функції файлу useClicker.js
handleClick() Обробляє клік користувача по головній кнопці та додає гроші на баланс.

getPassiveIncome() / getClickPower() Розраховують поточну швидкість пасивного заробітку та силу одного кліку з урахуванням бонусів престижу чи штрафів від вірусів.

buyUpgrade(type, baseCost) Перевіряє баланс гравця, списує потрібну суму та підвищує рівень обраного апгрейду в магазині.

openCase() Реалізує механіку лотереї при відкритті кейса: або подвоєння ставки, або повна втрата вартості кейса.

triggerPrestige() Очищує поточний баланс та рівні покращень, нараховуючи гравцеві зароблені преміум-монети.

Структура компонентів (HTML-розмітка)
<StatusBar /> — верхня панель для відображення балансу, швидкості доходу, сили кліку та монет престижу.

<ClickButton /> — центральна зона з великою кнопкою для кліків та кнопкою покупки кейсів.

<Upgrades /> — блок магазину, який виводить список покращень та кнопок для їхньої купівлі.

<PrestigeAndSkins /> — бічна панель із кнопками для рестарту гри та перемикання скінів.

Блок сповіщень в <App /> — відображає червоне вікно з попередженням, якщо активна хакерська атака.

Додатково
Сторінка використовує математичний модуль formulas.js для розрахунку зростання цін, сервіс storage.js для збереження даних у LocalStorage, а також CSS-стилі з файлу Themes.scss для плавної зміни візуальних тем додатка.
