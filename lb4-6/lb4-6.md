Лабораторна робота №4-6
Тема: "Фільмова база"
Мета: Розробка односторінкового застосунку для роботи з API за допомогою асинхронного JavaScript.
Що робить програма
Завантажує серіали: Одразу при відкритті сторінки підтягує список шоу з TV Maze API.

Показує картки: Кожне шоу виводиться як окрема картка з обкладинкою, назвою, оцінкою та жанрами.

Шукає в реальному часі: Можна вводити назву в поле пошуку, і список на екрані сам фільтрується.

Сортує список: Дозволяє розставити фільми за алфавітом або за рейтингом (від вищого до нижчого).

Повідомляє про проблеми: Якщо вимкнути інтернет чи впаде сервер, на сторінці з'явиться зрозумілий текст про помилку.

Головні функції у файлі app.js
fetchShows()
Потрібна для завантаження даних з інтернету. Вона робить запит до API, перевіряє, чи сервер відповідає, і бере перші 50 фільмів, щоб сторінка швидко працювала. Якщо все добре — запускає малювання карток, якщо ні — виводить помилку.

renderShows(shows)
Ця функція очищає сторінку від старих карток і малює нові. Вона перебирає фільми, за допомогою деструктуризації витягує потрібні поля (назву, картинку) і через шаблонні рядки (код у зворотних лапках) вставляє їх у HTML-контейнер.

handleFilterAndSort()
Спрацьовує щоразу, коли ми щось пишемо в пошуку або міняємо сортування. Вона бере початковий список, фільтрує його методом .filter() за назвою, потім сортує методом .sort() (за абеткою або рейтингом) і знову викликає renderShows(), щоб оновити екран.

Структура HTML
#searchInput — звичайне текстове поле, куди користувач вводить назву для пошуку.

#sortSelect — випадаючий список, де вибирають режим сортування.

#showsContainer — порожній блок-сітка, куди JavaScript додає готові картки з фільмами.

#error-message — блок для тексту помилки. Зазвичай він прихований і показується лише тоді, коли щось зламалося.

Оформлення та дизайн (CSS)
Зовнішній вигляд налаштований у файлі style.css. Головне тут — використання сітки CSS Grid для контейнера з фільмами. Завдяки цьому картки автоматично підлаштовуються під розмір екрану (і на телефоні, і на комп'ютері все виглядає рівно). Також у CSS прописані прості стилі: тіні та закруглені кути для карток, гарні відступи та червоний колір для повідомлення про помилку.
