Лабораторна робота: Конструктор резюме
Проєкт є простим вебдодатком, який збирає дані користувача через діалогові вікна браузера, обробляє їх та динамічно виводить готове резюме на сторінку.
Також реалізовано збереження результату в локальне сховище браузера.

Мета роботи
Закріпити на практиці роботу з базовим синтаксисом JavaScript та суворим режимом "use strict".

Реалізувати валідацію даних за допомогою функцій вищого порядку, замикань та каррінгу.
Організувати структуру коду через класи ES6 (наслідування, конструктори, геттери/сеттери).
Навчитися працювати з DOM-деревом та localStorage.

Структура проєкту
lb1.html — HTML-розмітка сторінки з кнопкою запуску та контейнером для виведення результату.
lb1.css — базові стилі для оформлення інтерфейсу та блоків резюме.
lb1.js — файл, який містить всю логіку застосунку.

Що реалізовано в коді
1. Валідація та замикання
Усі скрипти працюють у режимі "use strict".
Створено карровану функцію validateLength(minLength). Вона повертає іншу функцію, яка перевіряє, чи рядок не порожній і чи має він достатню довжину після видалення пробілів (.trim()).
Через цю функцію перевіряється правильність введення імені та навичок (мінімум 2 символи).

2. Об'єктно-орієнтоване програмування (ООП)
Код структуровано за допомогою класів:

ResumeBlock — базовий клас для всіх секцій резюме, має метод getHTML() для генерації заголовків.
PersonalInfo — клас для особистих даних, наслідує ResumeBlock. Вік користувача захищено через геттер і сеттер (дозволяє вводити лише числа від 1 до 99). Для виведення використовує super.getHTML().
TextBlock — універсальний клас для блоків "Освіта" та "Досвід роботи". Якщо користувач нічого не ввів, підставляється дефолтний текст.
Resume — головний клас, який приймає об'єкти інших класів, формує список навичок через цикл for...of та рендерить фінальну розмітку в DOM.

3. Взаємодія з DOM та збереження даних
Збір даних починається після кліку на кнопку "Почати введення даних".
Текстові дані збираються через prompt(). Якщо ім'я не проходить валідацію, скрипт зупиняється через return та виводить alert з помилкою.
Навички додаються динамічно у циклі while, поки користувач не натисне "Скасувати".
Готовий об'єкт резюме виводиться в консоль розробника для перевірки та записується в localStorage у форматі JSON.
